### Glossary / decision notes

- **Top-level audio** means Chat request `audio` used with output `modalities`; it is not the same as assistant message `audio` replay metadata.
- **Assistant audio replay** means `messages[].audio` / `llm.Message.Audio`, currently Chat-message scoped and not a request-level audio-generation config.
- **Structured output** means OpenAI `response_format` / Responses `text.format`; Anthropic `output_config.format` is not automatically the same concept in current AxonHub code.
- **Output config effort** means Anthropic `output_config.effort`; only this subfield has a common bridge through reasoning effort. `format` and `task_budget` remain Anthropic-specific unless implementation changes.
- **Request instructions** means Responses create-request `instructions` that converts through system messages. **Response instructions** means response-object `instructions`, which must stay a separate row.
- **Core Responses input items** means string input, `message`, `input_text`, `input_image`, and `input_audio`. `input_file`, tool/search-like items, and compaction/raw-only families need separate rows.
- **Core Responses output items** means output message/text, function/custom calls, reasoning, image-generation result, and common annotations. Computer/file-search/tool-search/web-search extended items need separate rows.
- **Raw-preserve** means same-protocol replay via provider sidecar or metadata; it does not imply cross-protocol semantic conversion.
- **Intentional lossy/unsupported** means the target protocol lacks an equivalent field or current product design should not invent one. These rows should be documented rather than forced into misleading mappings.
- **Document vs file** must stay explicit: common `Document` does not automatically cover Chat official file parts or Responses `input_file` until source and implementation are aligned.
- **Tool block boundary**: content-block shape belongs to this batch, but full tool schema and invocation semantics should cross-reference the tool/MCP batch.
