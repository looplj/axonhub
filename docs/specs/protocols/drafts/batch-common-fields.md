Scope: field inventory and official meanings only for Batch 1, Batch 2 fields assigned to Agent 1, and Batch 10 simple compatibility fields (`seed`, `n`).

Boundaries:

- No conversion strategy.
- No code ownership or implementation-path lookup.
- No edits to the strict verification matrix.
- `stream` here means request-level boolean only, not stream events/chunks/deltas.
- `absent from baseline` means the local protocol baseline field list for that source protocol does not expose the field as a request top-level field.

### Glossary / decision notes

- **request-level `stream`** means the top-level request boolean only. It never implies compatibility of stream event names, chunk schemas, SSE framing, deltas, or termination events.
- **common-abstraction field** means AxonHub has a common storage path such as `llm.Request`, but it does not by itself prove protocol value domains are equivalent.
- **native-field** means the target protocol has its own wire field. A field can be both common-abstraction and native-field when adapters copy it through common storage.
- **deprecated-compat** means preserve/bridge only for compatibility with older client fields. Do not use it to redefine newer fields such as `safety_identifier`.
- **metadata map** means OpenAI-style arbitrary key/value metadata subject to OpenAI map constraints. It is not the same thing as Anthropic `metadata.user_id`.
- **identity metadata** means Anthropic `metadata.user_id` and the deprecated OpenAI `user` compatibility bridge. It is narrower than arbitrary metadata and must carry a semantic caveat.
- **value-vocabulary caveat** means the field name matches but allowed values or meanings differ by protocol; `service_tier` is the standing example in this batch.
- **range-loss note** means the source protocol accepts a numeric range that the target may not accept; `temperature` OpenAI `0..2` to Anthropic `0..1` is the standing example.
- **unsupported/absent direction** means the target baseline lacks an equivalent field. The matrix should record loss/unsupported behavior rather than inventing a mapping.
